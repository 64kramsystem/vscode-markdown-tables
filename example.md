# Markdown Tables example

Select a complete row and press Cmd+B / Ctrl+B. Place the cursor in the table and run **Markdown Tables: Sort by column[s]**, entering `team, name`.

| Name | Team | Color | Notes |
| :--- | :--- | :--- | :--- |
| Zoe | Blue | lightblue | `a\|b` |
| Alice | Red | #ffd6d6 | **Already bold** |
| Bob | Blue | honeydew | A pipe: \| |
| Ben | Blue | invalid | No background |

Open the built-in Markdown preview to see the row colors.
